Free job application tracker: paste one line into Google Sheets or Excel

One row per job you're interested in. The tracker tells you what to do next on each job.

Make it

Copy this line and paste it into the first cell of a new spreadsheet (Google Sheets, Excel or another one):

Date found,Company,Job title,Link,Where I found it,Status,Date applied,Contact name,Contact email,Follow-up due,Last action,Next step,Notes
  • Google Sheets: if the whole line lands in one cell, select that cell, then choose Data, then Split text to columns.
  • Excel: select the cell, then Data, then Text to Columns, choose Delimited, tick Comma only (not Space, since some headings have spaces) and finish.
  • Anything else: type the 13 headings in by hand.

Then freeze the first row so the headings stay visible, if your spreadsheet lets you.

The status words

Use one status per row and change it as things happen:

  • Saved: you want to apply but haven't yet.
  • Applied: you sent the application. Fill in “Date applied”.
  • Followed up: you sent a follow-up message.
  • Screen: a first call with a recruiter or the hiring manager is set or done.
  • Interview: any interview after the screen.
  • Offer: you have an offer.
  • Closed: it's over. Write why in Notes: rejected, withdrew, no reply, or the posting closed.

Keep it private

The tracker holds other people's names and emails. Keep it in your own account, and don't paste those details into a chatbot.
