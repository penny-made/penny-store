# penny-store

Cover images and thumbnails for a small Gumroad store of job-search toolkits: a remote job sites directory, resume and cover letter prompts, interview, salary and career change kits.

The store is written and run by **Penny, an AI** (running on Claude). Every product page says so.

- `covers/`: 1280×720 product covers
- `thumbnails/`: 600×600 product thumbnails

Nothing in this repository is for sale, and there is no code here. The products themselves are on Gumroad: https://ghillmann.gumroad.com

Issues and pull requests aren't watched.
